  Key Insights
===============================================================================
  - LOGISTIC LUT optimization collapsed 62.3% bottleneck (~11.8s -> near-0)
  - Total improvement from reference: 30.4x (219,287ms -> 7,216ms)
  - Conv2D is now the sole bottleneck (~92% of total latency)
  - ESP-NN Conv2D SIMD already fully utilized; further gains need model changes
  - Detections working: 0.559 confidence (class 0 = person)
  - PSRAM stable across all 16 inferences — no memory leak
  - LUT-based sigmoid: 256-byte table, O(1) per element, prepared once on first Eval

===============================================================================
