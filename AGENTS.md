# RescueVision Edge — Session Context

## Project
ESP32-S3 YOLOv8n INT8 victim detection for search & rescue (paper).

## Hardware
- **Board:** XIAO ESP32S3 Sense (seeed_xiao_esp32s3)
- **Port:** `/dev/cu.usbmodem31201`
- **CPU:** 240 MHz | Flash: 8 MB | PSRAM: 8 MB
- **PlatformIO:** Framework = Arduino, partition = max_app_8MB.csv
- **Upload:** `upload_resetmethod = cdc`, `upload_speed = 921600`

## Build Commands
```bash
pio run --project-dir deployment/esp32-s3 --target upload
```

## Model
- **File:** `training/quantized/yolov8n_int8.tflite` (3,386,338 bytes)
- **Input:** `[1, 192, 192, 3]` INT8 signed (scale=0.003922, zp=-128)
- **Output:** `[1, 84, 756]` INT8 signed (scale=0.005039, zp=-128)
- **Conversion:** `training/scripts/03_quantize.py` sets `inference_input_type=tf.uint8`
- **C header:** Generated by `training/scripts/05_export_for_edge.py`

## WDT Fix (Critical for Dev)
- TWDT (TG1 WDT, 300ms timeout) resets device during `AllocateTensors()`
- Fix: `esp_task_wdt_deinit(); esp_task_wdt_init(60, false); esp_task_wdt_add(NULL);`
- Also needed: `heap_caps_malloc()` for tensor arena in PSRAM (not `.psram.data` section attribute)
